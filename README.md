# Telecom-Customer-Churn-Prediction

Project By: Gaurav Singh
Course: BCA (Data Science & Artificial Intelligence)

Project Overview

This project focuses on analysing customer churn in the telecommunications industry. Customer churn occurs when customers stop using a company's services. Predicting churn can help businesses identify customers who may leave and develop suitable retention strategies.

Objectives

- Understand customer churn patterns.
- Explore customer data and identify relevant factors.
- Analyse customer behaviour using predictive analytics.
- Support customer retention through data-driven insights.

Tools and Technologies

- IBM SPSS Modeler
- CHAID Decision Tree
- Data preprocessing and exploratory analysis

Methodology

1. Data preparation and cleaning.
2. Selection of relevant customer attributes.
3. Building a CHAID decision tree model.
4. Identifying customer groups with higher churn risk.
5. Interpreting the results for customer retention.

Expected Outcome

The project demonstrates how predictive analytics can help identify high-risk customer groups and support better retention decisions.
